# Домашнее задание №4 по Go

**Группа:** BHEMBD-25  
**Студент:** Арсений Паниклов

Тема: «Объектно-ориентированное программирование».

Проект продолжает развитие сервиса Ledger из ДЗ №3. Валидация
транзакций и бюджетов вынесена в единый интерфейс `Validatable`.

## Реализовано

- интерфейс `Validatable` с методом `Validate() error`;
- валидация `Transaction`: положительная сумма, непустая категория и
  заданная дата;
- валидация `Budget`: положительный лимит и непустая категория;
- полиморфная функция `CheckValid(Validatable) error`;
- проверка данных до добавления в Ledger;
- сохранение логики ДЗ №3: загрузка бюджетов из JSON, контроль лимитов и
  отклонение транзакций сверх бюджета;
- модульные тесты валидации и бизнес-логики.

## Требования

- Go 1.27 или новее.

## Запуск

```powershell
go run .
```

Программа показывает работу `Validatable`, загружает бюджеты из
`budgets.json`, добавляет допустимые транзакции и отклоняет операцию,
превышающую лимит.

## Проверка

```powershell
go test ./...
go vet ./...
```

## Структура проекта

- `main.go` — демонстрация полиморфной валидации и работы Ledger;
- `ledger.go` — структуры, валидация и бизнес-логика;
- `ledger_test.go` — модульные тесты;
- `budgets.json` — пример исходных бюджетов.
